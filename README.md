# INTER PACK — сайт компании

Статический одностраничный сайт (HTML / CSS / JS, без сборки) с переключением языков RU / EN / UZ. Все разделы (Главная, О компании, Достижения, Продукция, Видео, Команда, Связаться, Контакты) — это секции одной страницы `index.html`, между которыми меню плавно прокручивает. Карточка товара открывается как модальное окно поверх страницы.

## Структура

```
index.html            Вся страница целиком: все секции + модальное окно карточки товара
css/style.css         Общие стили
css/blog.css           Стили страниц блога
js/i18n.js             Тексты на RU / EN / UZ (используются как значения по умолчанию)
js/cms-override.js     Подтягивает отредактированные в CRM тексты поверх значений из i18n.js
js/main.js             Переключение языка, шапка, плавный скролл по якорям, подсветка активного пункта меню (scrollspy), анимации при прокрутке
js/counters.js         Анимация чисел в секции «Достижения»
js/product-modal.js    Рендер карточки товара в модальном окне (открывается кнопкой «Подробнее»)
js/contact-form.js     Отправка формы заявки
js/video.js            Логика кнопки Play в секции «Видео»
js/blog.js             Рендер списка статей и отдельной статьи блога

admin/                 CRM-панель (защищена логином) — тексты, фото, блог
includes/               Общий PHP-код (БД, сессии, CSRF, контент, загрузка фото) — недоступен из браузера
api/                    Публичные JSON-эндпоинты для фронтенда (content.php, blog.php)
blog/                   Публичные страницы блога (index.php — список, post.php — статья)
data/                   SQLite-база (создаётся автоматически) + схема текстов по умолчанию
```

## Как устроена навигация

Пункты меню — обычные якорные ссылки (`#about`, `#products` и т.д.), клик по ним плавно прокручивает страницу к нужной секции (`js/main.js`, функция `initAnchorNav`). Активный пункт меню подсвечивается автоматически по мере прокрутки (`initScrollspy`, на основе `IntersectionObserver`).

Карточка товара в «Продукции» — не отдельная страница, а модальное окно: клик по «Подробнее» вызывает `js/product-modal.js`, которое подставляет данные нужного товара в разметку `#productModal` и показывает её поверх страницы. Кнопка «Оставить заявку» внутри модалки закрывает её и прокручивает к разделу «Связаться».

## Важно при обновлении css/js

Ссылки на `css/style.css` и все `js/*.js` в `index.html` подключены с версией в конце (`?v=3`). Это нужно, чтобы браузеры посетителей не показывали старую закэшированную версию стилей/скриптов после обновления сайта. **При каждом изменении `css/style.css` или любого файла в `js/` увеличивайте число `v=` во всех тегах `<link>`/`<script>` в `index.html` на 1** — иначе часть посетителей будет видеть сайт сломанным (старые стили + новая разметка) до тех пор, пока не очистят кэш вручную.

## Что нужно заменить перед запуском в продакшен

Сайт полностью готов по структуре, анимациям и текстам на 3 языках, но использует **заглушки** вместо реальных медиаматериалов:

1. ~~Логотип~~ — подключён: `assets/logo-icon.svg` (в шапке) и `assets/logo-full.svg` (полный лого с текстом, для других нужд).
2. **Фон главной секции** — `assets/images/backgrounds/home-hero.webp` (уже подключён, при необходимости просто замените файл тем же именем).
4. **Остальные фотографии** — блоки с классом `.ph` в разделах «О компании», «Продукция», «Команда» и постер «Видео» всё ещё стилизованные градиентные плашки с иконками. Заменить так же, как главную галерею — добавить `<img class="ph-photo" src="..." onerror="this.remove()">` первым элементом внутри `.ph`, по аналогии с `index.html`.
5. **Видео** — в секции «Видео» подключите файл `assets/video/company.mp4` (сейчас файла нет, поэтому проигрывается заглушка-постер).
6. **Команда** — ФИО и фото в секции «Команда» — примеры для демонстрации вёрстки, замените на реальных сотрудников.
7. **Форма заявки** отправляется через сервис [FormSubmit](https://formsubmit.co/) на `inter.pack@mail.ru` без бэкенда. **Важно:** при первой отправке FormSubmit присылает на `inter.pack@mail.ru` письмо с подтверждением — нужно один раз перейти по ссылке в этом письме, иначе заявки не будут приходить.
8. **Карта** — встроена через `google.com/maps` embed по координатам 41°19'43.4"N 69°24'55.2"E, ключ API не требуется.
9. Ссылки на Telegram/Instagram в секции «Контакты» — заглушки (`t.me/interpack`, `instagram.com/interpack`), замените на реальные.

## CRM-панель (редактирование текста, фото и блог)

Сайт остаётся статическим HTML по умолчанию, но поверх него подключена небольшая админ-панель на PHP + SQLite, позволяющая менять контент без правки кода.

**Требования хостинга:** PHP 8+ с расширениями `pdo_sqlite` и `gd` (есть практически на любом обычном/shared-хостинге с поддержкой PHP — отдельная база MySQL не нужна, SQLite хранится в одном файле `data/cms.sqlite`). Если хостинг отдаёт только статические файлы (без PHP) — сам сайт `index.html` продолжит работать как раньше, просто CRM и блог будут недоступны.

**Первый запуск:**
1. Откройте `https://ваш-домен/admin/` (или `/admin/setup.php`) — страница создания первого аккаунта откроется только один раз, до того как создан хоть один администратор.
2. Придумайте логин и пароль (от 8 символов) и сохраните их в надёжном месте — после создания аккаунта страница настройки перестаёт работать.
3. Дальше вход — через `/admin/login.php`, пароль можно сменить в разделе «Мой аккаунт».

**Что можно делать в CRM:**
- **Тексты сайта** (`/admin/content.php`) — все тексты из `js/i18n.js` на RU/EN/UZ, сгруппированные по разделам, включая характеристики каждого товара. Если вернуть исходный текст — поле перестаёт считаться «изменённым».
- **Фотографии** (`/admin/photos.php`) — замена ключевых изображений сайта (фон главной, фото о компании, товары, логотип и т.д.) загрузкой нового файла; старое фото автоматически сохраняется в `assets/images/_backups/`.
- **Блог / новости** (`/admin/blog.php`) — создание, редактирование, публикация и удаление статей (заголовок, краткое описание, текст и обложка на 3 языках). Статьи видны на сайте в разделе «Блог» только после публикации.

**Как это работает технически:** `js/cms-override.js` при загрузке страницы запрашивает `api/content.php` и подменяет тексты поверх статических значений из `i18n.js` — с таймаутом в 2.5 секунды и тихим откатом к статике, если бэкенд недоступен. Фото в CRM загружаются **в те же самые пути**, что уже используются в HTML/CSS, поэтому замена фото не требует правок кода.

**Безопасность:** пароль хранится в виде bcrypt-хеша, вход защищён от перебора (блокировка после 8 неудачных попыток за 5 минут) и CSRF-токенами на всех формах. Папки `data/` и `includes/` закрыты от прямого доступа через `.htaccess` (работает на Apache — большинство shared-хостингов; если у вас Nginx, нужно будет попросить хостинг-провайдера добавить аналогичное правило). Рекомендуется подключить HTTPS на домене, если он ещё не подключён.

## Запуск локально

Файл статический, сборка не нужна. Достаточно любого локального сервера, например:

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000/index.html`.

## Деплой

Сам сайт (`index.html` и всё в `css/`, `js/`, `assets/`) можно разместить на любом статическом хостинге (GitHub Pages, Netlify, Vercel, обычный веб-сервер). Для CRM-панели и блога нужен хостинг с поддержкой **PHP 8+** (обычный shared-хостинг подходит) — см. раздел «CRM-панель» выше.
