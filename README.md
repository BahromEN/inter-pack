# INTER PACK — сайт компании

Статический одностраничный сайт (HTML / CSS / JS, без сборки) с переключением языков RU / EN / UZ. Все разделы (Главная, О компании, Достижения, Продукция, Видео, Команда, Связаться, Контакты) — это секции одной страницы `index.html`, между которыми меню плавно прокручивает. Карточка товара открывается как модальное окно поверх страницы.

## Структура

```
index.html            Вся страница целиком: все секции + модальное окно карточки товара
css/style.css         Общие стили
js/i18n.js             Тексты на RU / EN / UZ
js/main.js             Переключение языка, шапка, плавный скролл по якорям, подсветка активного пункта меню (scrollspy), анимации при прокрутке
js/hero-slider.js      Слайдер в секции «Главная»
js/counters.js         Анимация чисел в секции «Достижения»
js/product-modal.js    Рендер карточки товара в модальном окне (открывается кнопкой «Подробнее»)
js/contact-form.js     Отправка формы заявки
js/video.js            Логика кнопки Play в секции «Видео»
```

## Как устроена навигация

Пункты меню — обычные якорные ссылки (`#about`, `#products` и т.д.), клик по ним плавно прокручивает страницу к нужной секции (`js/main.js`, функция `initAnchorNav`). Активный пункт меню подсвечивается автоматически по мере прокрутки (`initScrollspy`, на основе `IntersectionObserver`).

Карточка товара в «Продукции» — не отдельная страница, а модальное окно: клик по «Подробнее» вызывает `js/product-modal.js`, которое подставляет данные нужного товара в разметку `#productModal` и показывает её поверх страницы. Кнопка «Оставить заявку» внутри модалки закрывает её и прокручивает к разделу «Связаться».

## Что нужно заменить перед запуском в продакшен

Сайт полностью готов по структуре, анимациям и текстам на 3 языках, но использует **заглушки** вместо реальных медиаматериалов:

1. ~~Логотип~~ — подключён: `assets/logo-icon.svg` (в шапке) и `assets/logo-full.svg` (полный лого с текстом, для других нужд).
2. **Фотографии галереи на главной** — положите 10 фото в `assets/images/hero/`, названные `hero-01.jpg` … `hero-10.jpg` по порядку слайдов (см. подписи `hero.slides.0…9` в `js/i18n.js`). Пока файла нет — слайд показывает прежнюю иконку-заглушку, ничего не ломается; как только файл появится по правильному имени, он подставится автоматически.
4. **Остальные фотографии** — блоки с классом `.ph` в разделах «О компании», «Продукция», «Команда» и постер «Видео» всё ещё стилизованные градиентные плашки с иконками. Заменить так же, как главную галерею — добавить `<img class="ph-photo" src="..." onerror="this.remove()">` первым элементом внутри `.ph`, по аналогии с `index.html`.
5. **Видео** — в секции «Видео» подключите файл `assets/video/company.mp4` (сейчас файла нет, поэтому проигрывается заглушка-постер).
6. **Команда** — ФИО и фото в секции «Команда» — примеры для демонстрации вёрстки, замените на реальных сотрудников.
7. **Форма заявки** отправляется через сервис [FormSubmit](https://formsubmit.co/) на `inter.pack@mail.ru` без бэкенда. **Важно:** при первой отправке FormSubmit присылает на `inter.pack@mail.ru` письмо с подтверждением — нужно один раз перейти по ссылке в этом письме, иначе заявки не будут приходить.
8. **Карта** — встроена через `google.com/maps` embed по координатам 41°19'43.4"N 69°24'55.2"E, ключ API не требуется.
9. Ссылки на Telegram/Instagram в секции «Контакты» — заглушки (`t.me/interpack`, `instagram.com/interpack`), замените на реальные.

## Запуск локально

Файл статический, сборка не нужна. Достаточно любого локального сервера, например:

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000/index.html`.

## Деплой

Подойдёт любой статический хостинг (GitHub Pages, Netlify, Vercel, обычный веб-сервер/хостинг) — просто загрузить содержимое папки как есть.
