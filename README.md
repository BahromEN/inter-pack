# INTER PACK — сайт компании

Статический многостраничный сайт (HTML / CSS / JS, без сборки) с переключением языков RU / EN / UZ.

## Структура

```
index.html         Главная — полноэкранная галерея продукции (10 слайдов)
about.html          О компании
achievements.html   Достижения — анимированная статистика
products.html       Каталог продукции (6 карточек)
product.html        Карточка товара (шаблон, ?id=0..5)
video.html          Видео о компании
team.html           Руководство и менеджеры
contact.html        Форма заявки
contacts.html       Контакты + карта
css/style.css       Общие стили
js/i18n.js          Тексты на RU / EN / UZ
js/main.js          Переключение языка, шапка, анимации при скролле
js/hero-slider.js   Слайдер на главной
js/counters.js      Анимация чисел на странице «Достижения»
js/product-detail.js  Рендер карточки товара по ?id=
js/contact-form.js  Отправка формы заявки
js/video.js         Логика кнопки Play на странице видео
```

Меню, подвал и переключатель языка продублированы на каждой странице (простые статические html-файлы, без сборщика).

## Что нужно заменить перед запуском в продакшен

Сайт полностью готов по структуре, анимациям и текстам на 3 языках, но использует **заглушки** вместо реальных медиаматериалов:

1. **Логотип** — сейчас нарисован упрощённый SVG-знак «INTER PACK» в `<header>` каждой страницы. Замените на настоящий логотип компании (SVG или PNG).
2. **Фотографии** — все блоки с классом `.ph` (слайды на главной, фото в разделе «О компании», карточки продукции, фото команды, постер видео) сейчас — стилизованные градиентные плашки с иконками. Замените их на `<img>` с реальными фотографиями продукции, производства и сотрудников.
3. **Видео** — на `video.html` подключите файл `assets/video/company.mp4` (сейчас файла нет, поэтому проигрывается заглушка-постер).
4. **Команда** — ФИО и фото в `team.html` — примеры для демонстрации вёрстки, замените на реальных сотрудников.
5. **Форма заявки** (`contact.html`) отправляется через сервис [FormSubmit](https://formsubmit.co/) на `inter.pack@mail.ru` без бэкенда. **Важно:** при первой отправке FormSubmit присылает на `inter.pack@mail.ru` письмо с подтверждением — нужно один раз перейти по ссылке в этом письме, иначе заявки не будут приходить.
6. **Карта** — встроена через `google.com/maps` embed по координатам 41°19'43.4"N 69°24'55.2"E, ключ API не требуется.
7. Ссылки на Telegram/Instagram в `contacts.html` — заглушки (`t.me/interpack`, `instagram.com/interpack`), замените на реальные.

## Запуск локально

Файлы статические, сборка не нужна. Достаточно любого локального сервера, например:

```
python3 -m http.server 8000
```

и открыть `http://localhost:8000/index.html`.

## Деплой

Подойдёт любой статический хостинг (GitHub Pages, Netlify, Vercel, обычный веб-сервер/хостинг) — просто загрузить содержимое папки как есть.
